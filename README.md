# metronome

终端节拍器：按指定速度打拍子。纯 Python 标准库，零依赖。

## 安装

不需要安装，直接运行：

```bash
python3 -m metronome 120
```

（在项目目录下执行，或把 `metronome.py` 放到 PATH 里。）

## 用法

```bash
metronome 120                  # 120 BPM 打拍子，首拍重音+响铃
metronome 90 --beats 3         # 3/4 拍：强-弱-弱
metronome 120 --duration 30s    # 跑 30 秒自动停（也支持 2m、1h）
metronome 120 --no-bell         # 只看不听（图书馆模式）
```

- 首拍显示 🔔 并响两声铃，其余拍显示 · 响一声——一眼/一耳分清小节。
- 计时基于 `time.monotonic()`，每次按"起始时间 + n×间隔"规划下一次敲击，**不累积漂移**。
- `Ctrl-C` 干净退出，并报告共敲了多少拍。

## 参数

| 参数 | 说明 |
|---|---|
| `bpm` | 速度，1–400 的整数 |
| `--beats N` | 每小节拍数（1–12），默认 4 |
| `--duration 30s` | 运行时长后自动停止（`s`/`m`/`h`） |
| `--no-bell` | 关闭终端铃声，只显示 |

## 诚实说明

- **铃声延迟因终端而异**：`\a` 只是请求终端响一声，实际延迟和音色取决于你的终端模拟器和系统；做严肃录音请用硬件节拍器。
- 长时间运行的精度受系统调度影响，普通练习足够，录音室级请绕行。
- 只做打拍子，不做调音、节拍型预设等花活。
